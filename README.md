# BusMate

**BusMate** is a real-time afternoon shuttle bus booking application designed for college students and faculty.

---

## Purpose of the Application

BusMate addresses the critical daily need for students and faculty to commute from their campus to their homes. It eliminates the uncertainty and stress associated with traditional college transport systems.

### Key Features & Benefits

#### 1. Real-Time Bus Tracking & Live Updates
- **Live Location**: Track the bus location on a map in real-time.
- **ETA Predictions**: Get accurate Estimated Time of Arrival (ETA) for the bus at your pickup location.
- **Dynamic Occupancy**: View live occupancy levels (e.g., 15/48 seats taken) to plan your commute better.
- **Push Notifications**: Receive instant alerts for bus arrival, delays, or route changes.

#### 2. Smart Booking System
- **Dynamic Route Optimization**: The system calculates the most efficient route to pick up all passengers, minimizing travel time.
- **Last-In, First-Out (LIFO) Priority**: Ensures fair allocation—those who book later get priority for earlier boarding, reducing gate-waiting anxiety.
- **Group Booking**: Book seats together with friends and colleagues.

#### 3. User Roles & Access Control
- **Student Mode**: Standard booking and tracking features.
- **Faculty Mode**: Priority booking access and management tools.
- **Driver Mode**: Interface for bus operators to view route details and passenger manifests.
- **Admin Dashboard**: Real-time monitoring of all buses, routes, and user activity.

#### 4. Social Integration & Gamification
- **Friend Invitations**: Invite friends to join and book seats together.
- **Group Management**: Create and manage groups for easier coordination.
- **Streak System**: Track consecutive days of using the service to encourage regular usage.
- **Badges & Rewards**: Unlock badges for consistent travel or inviting friends.

#### 5. Safety & Security
- **SOS Feature**: In-app emergency button to alert faculty and security in case of distress.
- **Verified Users**: Integration with college ID systems (mocked via Clerk) ensures only authorized users can access the service.
- **Faculty Monitoring**: Faculty can monitor bus movements for the safety of students.

#### 6. Modern User Experience
- **Sleek UI**: Modern, intuitive interface with dark mode support.
- **PWA Optimized**: Progressive Web App for seamless experience on desktop and mobile.
- **QR Code Tickets**: Dynamic QR code generation for secure and easy ticket verification.
- **User Reviews**: Rate the bus service and driver for quality assurance.
